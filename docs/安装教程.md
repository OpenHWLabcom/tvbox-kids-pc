# 机顶盒 → 少儿电脑 · 安装教程

把一台 **已 root 的安卓机顶盒**（实测：中兴 ZXV10 **B860AV1.1-T2** / zx296716 / Android 4.4.2）做成一台**给小学生用的桌面小电脑**：开机直进一个 Win 风格的简单桌面（浏览器 / 文件 / 设置），设置免密。

## 0. 你需要
- 一台 **已 root** 的安卓机顶盒（Android **4.4+**）。
- 能进盒子 root shell 的通道：**ADB**（`adb connect <IP>:5555`）或 **串口 TTL** shell。
- 本安装包（`kid.apk` + `kidboot.sh` + `一键安装.sh`）。

> 本机实测盒子：`ZXV10 B860AV1.1-T2`，192.168.31.161，Android 4.4.2 / armeabi-v7a。
> 部分运营商盒子 **ADB 只给 pull/push、shell 被锁** —— 那就用串口或已有的 SSH 拿 shell。

## 1. 把安装包拷到盒子
```
adb push kid-install /sdcard/kid-install
```
（或串口 SSH：`scp -r kid-install root@盒子:/sdcard/`）

## 2. 一键安装
在盒子上（root/shell）：
```
sh /sdcard/kid-install/一键安装.sh
```
它会：
- 装 `com.laifu.kids`（少儿电脑桌面 App）
- 部署 `/data/kidboot.sh`（开机把桌面拉前台）
- 把 `kidboot` 挂进 `/system/etc/init.zte.post_boot.sh`（先 `mount -o remount,rw /system`）

## 3. 设为唯一桌面（HOME）
Android 4.4 **没有** `pm set-home-activity`。做法是**卸载旧桌面**，本 App 即成为默认桌面：
```
pm list packages | grep -i launcher        # 找旧桌面包名
pm uninstall <旧桌面包名>                  # 例如旧 kiosk / 点歌台
```
（若原本是「家庭影院 KTV 点歌台」，`pm uninstall com.openhardwarelab.ktv`）

**重启盒子** → 开机应**直接进入「少儿电脑」桌面**。

## 4. 验证
```
# 前台是否为本 App：
dumpsys window windows | grep mCurrentFocus
# 应含 com.laifu.kids
```

## 5.（可选）浏览器 / 键盘优化
- **浏览器**：装 Firefox（`org.mozilla.firefox`）；桌面「浏览器」图标会优先用它。
  想要**电脑版网页**：Firefox 设置里把主页设为 `https://www.baidu.com/`，并在 `about:config` 里
  设 `general.useragent.override` 为桌面 UA。
- **键盘**：有实体键盘时不想弹软键盘 → `settings put secure show_ime_with_hard_keyboard 0`；
  中文输入用系统输入法（如搜狗）。
- 桌面支持**方向键导航 + 回车打开**（原生焦点）。

## 6. 常见问题
- **点图标没反应**：确认本 App 是**原生控件版**且**全屏**（我们已去掉标题栏——标题栏会把内容顶下 ~84px 导致点击偏移）。
- **`pm install` 报空间不足**：`/data` 要留 **≥10% 空闲**；清缓存（如 chroot 的 `apt` 缓存）后再装。
- **设置要密码**：本包桌面「设置」图标用 `com.android.settings/.Settings` + extra `needpassword=noneed` → 免密直进（视 ROM 而定）。

## 适配其它盒子
- 桌面图标指向的 App（浏览器/文件/设置）可按你的盒子改包名；
- 开机自启脚本（`kidboot.sh` / 挂钩子）按你的 ROM 调整。
