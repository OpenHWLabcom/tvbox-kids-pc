# 案例：B860AV1.1-T2 机顶盒 → 「小学生电脑」

> 把一台中兴 ZXV10 B860AV1.1-T2 机顶盒（原本被改造成「家庭影院 KTV 点歌机」）二次改造成 **给小学生用的桌面小电脑**。全程远程（SSH/ADB），不拆机、不改系统 App。

## 一、目标与硬件
- **目标**：开机直进一个简单、Win 风格、能上网/看文件/改设置的「少儿电脑」桌面。
- **盒子**：**ZXV10 B860AV1.1-T2** = 中兴微 **ZXIC zx296716(B16)** / A53 四核 / ~1GB / eMMC。
- **系统**：**Android 4.4.2 (sdk19)** / **armeabi-v7a(32位)** / **userdebug**；ROM `V815.60016`(2022-04)。
- **已有资产**：机内带一个 **Ubuntu 20.04 (aarch64) chroot**（`/data/linux`，前几次改造留下）。
- **IP**：192.168.31.161（DHCP）。

## 二、关键卡点与解法（本案例的核心经验）
| # | 卡点 | 解法 |
|---|---|---|
| 1 | 串口认芯片：TTL **只出不进**，115200 收不到 | 其实是**接线**问题（TX/RX 交叉）；接对后读到 `ROM6716V1→BL1→BL31(B16XX)` 坐实 ZXIC B16 |
| 2 | **ADB shell 被锁**（`pull/push` 正常，`adb shell`/`exec-out`/`am` 全挂） | 走 **SSH** 拿 root shell；ADB 只用来 pull/push + `adb reboot` |
| 3 | ⭐ **`ssh` 落在 chroot 里，`/data` ≠ 安卓 `/data`** | 操作安卓侧一律用 **`/proc/1/root/data/...`**；命令走 **`/root/and.sh "<cmd>"`**（chroot→Android 根 + BOOTCLASSPATH） |
| 4 | 开机自启 | 安卓侧 **`/data/kidboot.sh`**（等 boot_completed→拉桌面）+ 修 `/data/bootfix.sh`；hook 追加在 **`/system/etc/init.zte.post_boot.sh`** |
| 5 | 清掉旧「点歌机」 | `pm uninstall com.openhardwarelab.ktv` + 注释 startlinux 里 ktvnet 自启 |
| 6 | 自己写桌面 App | 新 App **`com.laifu.kids`**（源码 `~/kid-desktop/`，构建 `~/android-build/build-kids.sh`） |
| 7 | ⭐ 桌面**点图标没反应** | 根因①：Activity **系统标题栏**把内容顶下~84px（坐标全错）+ ②：老 **WebView(Chromium30) 的 JS 桥失效**。→ 改**纯原生控件** + **全屏去标题栏**(`Theme.NoTitleBar.Fullscreen`) |
| 8 | ⭐ **设置免密** | Settings 是 **ZTE 签名**系统 App（无密钥，重打包会坏）→ 反编译发现带 **`needpassword=noneed`**（String extra）即跳过密码门 → 桌面「设置」据此启动 |
| 9 | `/data` 空间紧 | 装 App 需 **≥10% 空闲(~500M)**；清 chroot 的 apt 缓存后装成 **Firefox** |
| 10 | 浏览器体验 | **桌面 UA**（`general.useragent.override`）→ 电脑版百度；主页=百度；**关「常用网站」Top Sites**；不恢复多标签；网页**不缩放** |
| 11 | 键盘输入 | 有实体键盘时**不弹软键盘**(`show_ime_with_hard_keyboard=0`)；**搜狗输入法**默认；桌面**方向键导航+回车打开** |
| 12 | 品牌 | 右下角水印 **OPEN HW LAB / 激发探索的勇气** |

## 三、成品（开机直进）
- **Win 风格「少儿电脑」桌面**（原生）：蓝色渐变壁纸 + 左侧图标 + 底部**任务栏**（"开始" + 时钟）+ **开始菜单**（含关机）+ 右下**品牌水印**。
- 图标：**浏览器**(Firefox，默认电脑版百度) · **文件**(FileBrower) · **设置**(免密直进)。
- 键盘/遥控/鼠标均可操作；点歌系统已清。

## 四、关键文件 / 命令速查
- 源码：`~/kid-desktop/`；构建：`cd ~/android-build && ./build-kids.sh` → `kid.apk`。
- 装 App：`/root/and.sh "pm install -r /data/local/tmp/kid.apk"`。
- 盒子侧脚本：`/data/kidboot.sh`、`/data/bootfix.sh`、`/data/startlinux.sh`、`/root/and.sh`。
- 登盒子：`ssh -i ~/.ssh/id_box root@192.168.31.161`（= Ubuntu chroot）。
- 操作安卓侧：`/root/and.sh "<cmd>"`；抓图：`and.sh "screencap -p /data/local/tmp/x.png"` → `scp` 出。
- 串口：FTDI `/dev/ttyUSB1 @115200`（只读日志）。

## 五、可复用教训
1. **改盒子先搞清"命令跑在哪层"**：chroot vs Android；`/proc/1/root` 是钥匙。
2. **老 WebView 不可靠**（JS 桥/缩放/点击）→ 关键 UI 用**原生控件**。
3. **Activity 记得去标题栏**，否则全屏坐标全偏。
4. **系统 App 别重打包**（厂商签名）；优先找它自身的开关/参数绕过。
5. `/data` 装不下大 App 时，先清缓存/腾到 ≥10%。
6. 免密/权限类需求，**反编译读 smali 找"官方开关"**往往比硬改省事、零风险。
